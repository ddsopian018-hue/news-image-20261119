The image is drawn in-session by `draw.py` (PIL, no stock photos) and `main.ts` copies it to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

To redraw the image from scratch:

```sh
python3 draw.py
```
